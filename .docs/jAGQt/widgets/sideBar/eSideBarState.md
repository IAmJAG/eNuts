## Overview & Design Context
Defines the visual/logical states of the SideBar used by `StatefullIcon` on the header (e.g. expanded vs collapsed).

---

## Classes

### `eSideBarState`
- **Purpose:** Enum of sidebar states for multi-state header icons.
- **Members:**
  - `Expanded` — sidebar expanded.
  - `Collapsed` — sidebar collapsed.

---

## Sample Usage

```python
from jAGQt.widgets.SideBar import eSideBarState

state = eSideBarState.Expanded
```
